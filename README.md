## 📌 About the Project

This is my **personal portfolio website**, designed and deployed as a **production-ready web application** to showcase my skills, projects, certifications, and achievements.

The project covers the **complete real-world deployment workflow**, including frontend development, version control, CI/CD, custom domain setup, DNS configuration, and SSL (HTTPS) troubleshooting.

---

## ✨ Features

- Fully responsive and mobile-friendly design  
- Professional UI/UX layout  
- Dedicated sections for:
  - About Me
  - Skills
  - Projects
  - Certifications
  - Achievements
  - Contact
- Custom domain with HTTPS enabled  
- Clean navigation and smooth user experience  
- Production deployment with continuous updates via GitHub

## 🛠️ Tech Stack

**Frontend**
- React
- TypeScript
- Vite

**Styling**
- Tailwind CSS

**Hosting & Deployment**
- Netlify
- GitHub (CI/CD)

**Domain & Security**
- Custom domain (`matheshmithra.in`)
- Netlify DNS
- SSL / HTTPS (Let’s Encrypt)

---

## 🔧 Deployment Workflow

1. Source code managed using **Git & GitHub**
2. Automatic deployment via **Netlify**
3. Custom domain connected to Netlify
4. DNS and nameserver configuration
5. SSL certificate issued and verified
6. Real-world SSL and DNS issues debugged and resolved
